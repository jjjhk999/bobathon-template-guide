Troubleshooting

막혔을 때 확인할 것

Notion 연결이 보이지 않아요

  1. Bob과 Notion에 같은 브라우저에서 로그인했는지 확인합니다.
  2. MCP 연결 화면을 새로고침합니다.
  3. 기존 연결을 해제한 후 OAuth 인증을 다시 진행합니다.

페이지 검색 결과가 없어요

  1. Notion에서 해당 페이지를 직접 열 수 있는지 확인합니다.
  2. 페이지 제목을 정확하게 프롬프트에 입력합니다.
  3. 운영진이 제공한 실습 워크스페이스에 연결했는지 확인합니다.

수정 권한이 없다고 나와요

페이지 오른쪽 위 공유 메뉴에서 본인의 권한이 편집 가능인지 확인합니다. 읽기 권한만 있다면 운영진에게 참가자용 하위 페이지를 요청하세요.

그래도 해결되지 않아요

운영진에게 다음 세 가지를 전달하면 빠르게 확인할 수 있습니다.

  • 실행한 프롬프트
  • 표시된 오류 메시지
  • 문제가 발생한 단계의 화면 캡처
운영진 연락 링크 입력

빠른 초기화

로그아웃보다 먼저 MCP 연결만 해제하고 다시 인증해 보세요. 대부분의 만료된 인증 문제는 이 단계에서 해결됩니다.
