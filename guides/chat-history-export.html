BoB 채팅 기록 내보내기

Bobathon에서 나눈 대화를 JSON 파일로 저장합니다.

1. 내보낼 대화 선택

Recent Tasks에서 내보낼 대화 오른쪽의 ⋮ 메뉴를 열고 Export를 선택합니다.

2. JSON 형식 선택

내보내기 형식에서 JSON · Structured data format (.json)을 선택합니다.

3. 결과물 제출

아래 링크를 눌러 Bobathon 결과물 제출 사이트로 이동한 뒤, 내보낸 JSON 파일을 첨부합니다.

Bobathon 결과물 제출 제출 사이트 열기 → https://bobathon-eval-backend.2dubxbn992ce.us-south.codeengine.appdomain.cloud/
완료: 제출 사이트에서 JSON 파일이 첨부됐는지 확인한 뒤 제출을 마칩니다.

제출 전 확인

  • 회사·고객 정보와 개인정보가 포함되지 않았는지 확인합니다.
  • 비밀번호, API 키, 토큰이 있다면 제출하지 않습니다.
  • 본인이 참여한 대화만 제출합니다.
